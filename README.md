# Le Planning Efficace

Le Planning Efficace est une application web gratuite pour organiser ses révisions, ses devoirs, ses évaluations et ses sessions de travail.

Site public : https://julianogueiracroucrou-collab.github.io/Le-Planning-Efficace/

## Fonctionnalités

- Planning de révisions
- Gestion des tâches et devoirs
- Minuteur focus
- Statistiques de progression
- Notes rapides
- Badges de motivation
- Répétition espacée
- Données conservées localement dans le navigateur

## Pour qui ?

L'application s'adresse aux lycéens, étudiants et utilisateurs qui veulent organiser leur temps de révision simplement depuis un navigateur.

## Confidentialité

Les données sont stockées localement dans le navigateur de chaque utilisateur. Un autre utilisateur qui ouvre le site ne voit pas l'espace personnel du créateur du site.
